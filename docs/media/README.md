# Gameplay capture

`gameplay.gif` is a continuous 12-second recording of the TI-Nspire LCD in
Firebird (CX II CAS, ordinary OS 6.4.0.74 and Ndless), captured on 2026-11-03.
It shows Necrobinder's **Strike**, Osty's **Unleash**, then **Offering** causing
the player and Osty to die. The in-game developer console prepared this test
encounter, hand and low health before recording; it is not a starter-deck run.

The final UI25 animated bilingual package was installed through ordinary USB.
All 12 program/resource files were read back and matched its build manifest.
Runtime: `ed5dd2564625779313aa2c71046079dee7506e76`.
Resources: `e98a6cb4ed29cd4e3bcaa597cff9ad089c6854f7`.

The GIF preserves the native **320×240** grid. Its 240 LCD samples are spaced
50 ms apart on the emulator clock and replay with the same timing, without
cuts, reordered frames or added holds. GIF encoding uses a 256-color palette
without dithering. The 20 samples per emulated second are a capture setting,
not a physical-calculator frame-rate measurement.
