## Concrete calculator-storage blocker

The complete original-resource pack is **231,312,495 bytes**, SHA-256
`d9adddc61c4f4f61b2ce50ee90960b112d752a694595ffa5f0feb2a6d9b204fb`, with
**45,724 images, 1,695 clips, 11,915 glyphs, 6,100 strings and 558 cards**.
It passes the runtime's bounded range-reader checks, but exceeds the physical
installation budget. Texas Instruments documents **90+ MB storage**, 64 MB
operating memory and a 320 x 240 screen for the CX II/CX II CAS:

https://education.ti.com/en/products/calculators/graphing-calculators/ti-nspire-cx-ii-cx-ii-cas/specifications

A larger code-level file limit cannot solve that storage constraint. The
launcher and up to three 262,144-byte save files also need room. No matching
0.17 calculator pair is represented as installable at this stage.

Private exact size-only trials retain every frame, dimension and original
raw image byte. They globally deduplicate **28,910 unique new frames** and
validate every independently compressed group by decoding it again:

| Independent LZMA2 group bounds | Groups | Exact provisional whole-file bytes |
| --- | ---: | ---: |
| 16 frames / 1 MiB raw | 1,866 | 117,396,313 |
| 64 frames / 1 MiB raw | 651 | 107,167,402 |

Both totals include original directories, retained old/static images, all
glyph/string data, alignment, frame descriptors and group headers. Neither
fits. The first serial trial was interrupted by the outer execution layer;
its journal remains unfinished. The subsequent four-worker trial separately
revalidated all 923 completed cached groups and passed. Nothing was
retroactively marked successful.

A separate bounded decoder prototype demonstrated fixed **28,544-byte**
probability storage, caller-provided output and freestanding native/ARM/WASM
compatibility. It is not integrated into the production repository because a
complete size-feasible lossless layout is still required. Full-canvas and
sparse pixel prediction are under investigation without deleting frames or
changing visual resolution. Their samples are not installation evidence.
