## Packaging and format boundary

The active UI17 conversion chain supports NSP2/41 throughout:
`predict_index_resources.py` → `complete_retained_resources_ui17.py` →
`content_tiles.py` / `ui12_resources.py` → `split_content.py` →
`storage_parts.py` → `package_release.py`. Historical append/font writers keep
their stage-specific inputs; they are not rerun over the final NSP2/41 pack.

The final audit found and fixed `language_resource_version` still rejecting
41 even though the converter/runtime accepted it. Commit `1ec2707` covers
NSL1, NSL2, NSL3-around-NSL1 and NSL3-around-NSL2, accepts 41, and rejects a
future logical 42 with otherwise valid unchanged container bounds. The
release helper entry point is included in these checks.

Unicode-derived seed tables require the associated copyright/permission
notice. Commit `c0aec0f` adds `third_party/unicode/LICENSE` to the player ZIP
under the unambiguous **`data/licenses/Unicode-License.txt`** name. A real
public-synthetic calculator ZIP test reads that notice back byte for byte,
rejects duplicate archive member names, checks NSP2/41 BUILD-INFO and confirms
that state contains only its empty directory. The final multipart delivery has
**23 main archive members**, including the additional notice, and
**15 optional-language archive members**. Original assets remain private.

The existing package tool verifies each archive member against its input.
No duplicate packaging or installed-size tool was introduced.

## Reproduce the resource gates

Paths below are relative to the same workspace layout; the original logical
English reference is `../private-ui17-storage/baseline-eng.nsp`.
The complete new defaults are
`../private-ui17-retained/work/{eng,zhs}-retained41.nsp`.

```sh
/lib64/ld-linux-x86-64.so.2 build/native/locale_editions_regression \
  ../private-ui17-retained/data
/lib64/ld-linux-x86-64.so.2 build/native/resource_content_regression \
  ../private-ui17-retained/work/eng-retained41.nsp \
  ../private-ui17-storage/baseline-eng.nsp
```

The final replay uses the driver built from `tests/locale_io_coalescing_regression.cpp`
and the same accepted core. Use a fresh private output directory for repetition;
the verification runner refuses to overwrite preserved evidence.

```sh
python3 tools/verify_resource_io_oracles.py \
  --binary build/native/final_resource_io_oracle \
  --interpreter /lib64/ld-linux-x86-64.so.2 --candidate-mode 3 \
  --data ../private-ui17-retained/data \
  --save ../private-ui17-device/fixtures/ui14-enemy-generated-cards.sav.tns \
  --progress ../private-ui17-device/fixtures/ui14-enemy-generated-cards.progress.tns \
  --baseline ../private-ui17-device/deferred-native-oracles \
  --earlier-english ../private-ui17-device/ui16-native-oracle \
  --output ../private-ui17-final-native-oracles-repeat \
  --runtime-checkpoint d4303baf9a720bbeed58c1bb1859ff63343afcd6
```

Executed commands, complete source identities, timing and exit status are in
the journals above. Formal reruns should use `tools/run_logged.py` with the
actual frozen checkout checkpoint, as the accepted runs did.
