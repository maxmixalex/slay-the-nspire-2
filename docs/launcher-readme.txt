Slay the Nspire 2 — calculator launcher / 计算器启动器

Place nSpire2.tns beside the complete data/ directory produced from your own
supported Slay the Spire 2 installation. Keep your existing state/ directory
when updating. Both full and reduced animation data use the same launcher.

将 nSpire2.tns 与用自己原版游戏转换得到的完整 data/ 目录放在同一目录。
升级时保留已有的 state/ 存档目录。完整动画与精简动画使用同一个启动器。

Installation / 安装说明：
https://github.com/maxmixalex/slay-the-nspire-2#readme
