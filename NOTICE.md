## Unicode seed tables

`src/seed_case_tables.inc` is generated from Unicode 15.1.0
`UnicodeData.txt` by `tools/generate_seed_case_tables.py`, with the recorded
.NET invariant simple-uppercase behavior. The source data's SHA-256 is
`2fc713e6a31a87c4850a37fe2caffa4218180fadb5de86b43a143ddb4581fb86`.

https://www.unicode.org/Public/15.1.0/ucd/UnicodeData.txt

`src/seed_legacy_prefix.inc` contains Unicode-derived range classifications
generated by `tools/generate_seed_legacy_prefix.py` from the documented
.NET 9 / ICU 74.2 invariant-culture prefix behavior. These bounded tables
implement the seed transformations described in `docs/porting.md#seeds-and-map-arithmetic`.
They contain no game assembly, localization text or font data; no ICU library
or original game binary is bundled with the source.

Copyright © 1991-2026 Unicode, Inc. The complete Unicode License V3 copyright
and permission notice is preserved in `third_party/unicode/LICENSE` and must
accompany distributions of these derived tables. The calculator packager
includes it at `data/licenses/Unicode-License.txt`; the optional offline HTML
packager also includes the complete text in its embedded distribution notices.

## Calendar culture facts

`include/ui_calendar_locale_data.inc` contains the bounded month names,
grammatical month forms, day-period markers and separators reported by .NET
9.0.22 / ICU 74.2 for the documented sixteen-language culture map.
`tools/generate_calendar_locale_data.py` reproduces this Unicode-derived table
from the optional reference oracle's culture metadata. It also assigns eleven
display-only identifiers to complete Thai month graphemes; those identifiers
contain no original font raster. The same Unicode License V3 notice above
applies and is included in source and calculator packages. The runtime includes
neither ICU nor original font files. Formatting scope and platform limits are
recorded in `docs/porting.md#calendar-localization`.

## Game data and animations

Slay the Spire 2, its text, visual assets, characters, logos and trademarks belong
to Mega Crit and the respective rights holders. This unofficial port is
not endorsed by or associated with Mega Crit. GPL licensing of this project's
code grants no additional right to redistribute original game content.

The converter builds private content packs from the player's installation.
The public repository does not distribute game data, assemblies, PCKs, game
fonts, calculator firmware or flash dumps. A gameplay recording in the
documentation illustrates the running port; the game artwork it depicts
remains the property of its respective rights holders. Raw capture sets and
converted game data are not part of the public launcher download.

`tools/animation.py` and `tools/setup_pose.py` implement a bounded converter for
the supplied Spine 4.2 data. Selected bone, slot, deform and draw-order tracks
are sampled offline, with limited IK and transform-constraint handling.
They do not bundle the Spine editor or a complete official runtime and do not
claim exact rendering parity. The official binary reader was consulted as a
format reference:

https://github.com/EsotericSoftware/spine-runtimes/tree/4.2

Only pre-rendered images and their animation-directory records are read on the
calculator. Screen layout, interaction and presentation are adapted for the calculator;
implementation details are described in `docs/porting.md`.

Game fonts are read locally by the converter. No installable font file is
included; only rasterized glyphs needed by the selected interface enter the
content pack.

The small Chinese bitmap subset used before a content pack is available is
derived from Noto Sans CJK SC, independently of the original game fonts.

## LZ4 and glyph encoding

The independent LZ4 block decoder and glyph RLE preserve image/coverage values.
Host-side python-lz4 supplies compression during conversion; no python-lz4 or
upstream LZ4 source/binary is bundled in the calculator runtime.

## Rich-text color math

`include/rich_rainbow.hpp` adapts the rainbow phase calculation from Godot
4.5.1 and samples Björn Ottosson's OkHSV color mathematics. The fixed-point
adaptation and numerical table retain the MIT notices in that header and in
`licenses/OkHSV-Godot-MIT.txt`; the latter must accompany binary redistributions.
The offline HTML packager includes it with the existing notices.
The pinned public sources, table reconstruction procedure and measured error
limits are documented in `docs/porting.md#rainbow-text-provenance`. These mathematical tables
contain no original game image, font or localization payload.

## Optional auxiliary-text glyph fallbacks

The private content conversion can use the real Noto Emoji and Noto Sans
Symbols2 fonts from Google Fonts to cover symbols absent from the pinned
game fonts. Only required glyphs are baked; font files remain private inputs.
These fonts are licensed under the SIL Open Font License 1.1. The complete
copyright notices and license terms are included in
`licenses/NotoEmoji-OFL.txt` and `licenses/NotoSansSymbols2-OFL.txt`, and are
carried into the calculator ZIP and offline HTML by the packaging tools.

Source: https://github.com/google/fonts/tree/main/ofl/notoemoji and
https://github.com/google/fonts/tree/main/ofl/notosanssymbols2.
